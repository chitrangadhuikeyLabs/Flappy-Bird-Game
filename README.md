
# Flappy Bird — Python + Pygame

A beginner-friendly Flappy Bird-style game built using Python and Pygame. 
The graphics use simple shapes, so no external image assets are required.

## Features

- Bird movement and gravity
- Randomly positioned pipe gaps
- Collision detection
- Score tracking
- Start and game-over screens
- Restart functionality
- Keyboard and mouse controls

## Requirements

- Python 3.10 or newer
- Pygame

## Controls

- SPACE or left-click: start, flap, or retry
- R: return to the title screen after game over
- ESC: quit

## Concepts demonstrated

- Python variables and data types
- Functions and return values
- Lists and dictionaries
- Loops and conditional statements
- Pygame graphics and events
- Game loops and physics
